1. Add Apple Smart App Banner

In:

resources/views/layouts/app.blade.php

inside the <head> section:

<meta name="apple-itunes-app" content="app-id=6753354778">

This automatically shows Apple's native install/open banner in Safari on iPhone and iPad.

2. Create Banner Partial

Create:

resources/views/partials/app-install-banner.blade.php
<div id="appInstallBanner" class="app-banner" style="display:none;">
    <button class="app-banner-close" onclick="closeAppBanner()">×</button>

    <img src="{{ asset('images/app-icon.png') }}" alt="Marketplace Naija">

    <div class="app-banner-text">
        <strong>Marketplace Naija</strong>
        <span>Buy & Sell Faster With Our App</span>
    </div>

    <a id="appInstallLink" href="#" class="app-banner-button">
        Install
    </a>
</div>

<script>
(function(){

    const iosUrl =
        "https://apps.apple.com/us/app/marketplace-naija-buy-sell/id6753354778";

    const androidUrl =
        "https://play.google.com/store/apps/details?id=com.app.marketplacenaija";

    const ua = navigator.userAgent || navigator.vendor || window.opera;

    const isAndroid = /android/i.test(ua);

    const isIOS = /iPhone|iPad|iPod/i.test(ua);

    const isSafari =
        /^((?!chrome|android).)*safari/i.test(ua);

    const banner =
        document.getElementById('appInstallBanner');

    const link =
        document.getElementById('appInstallLink');

    if(localStorage.getItem('appBannerClosed')){
        return;
    }

    if(isAndroid){
        link.href = androidUrl;
        banner.style.display = 'flex';
    }

    if(isIOS && !isSafari){
        link.href = iosUrl;
        banner.style.display = 'flex';
    }

})();

function closeAppBanner(){
    document.getElementById('appInstallBanner').style.display='none';

    localStorage.setItem(
        'appBannerClosed',
        'true'
    );
}
</script>
3. Include The Banner

Inside your main layout immediately after <body>:

@include('partials.app-install-banner')

Example:

<body>

@include('partials.app-install-banner')

@yield('content')

</body>
