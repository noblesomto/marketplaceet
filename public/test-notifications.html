📝 How to Test

  1. Get an API Token: Login to your account via /api/login and copy the bearer token
  2. Register Device Token: Paste your API token above and click "Register Token"
  3. Send Test Notification: Use the form above or the API endpoint:
    POST /api/test/notification
    Authorization: Bearer {your-token}
    Content-Type: application/json

    {"message": "Hello from API!"}
  4. Or use Artisan Command:
    php artisan notification:test --user=YOUR_USER_ID
  5. Keep this page open to receive notifications in real-time!
